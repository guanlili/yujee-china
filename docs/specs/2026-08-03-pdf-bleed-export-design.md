# PDF 导出出血选项设计

- 日期: 2026-08-03
- 影响面: `apps/web`(导出 UI 双端 + 栅格 PDF 渲染管线)
- 范围: 只动 PDF 导出;单页图/拼图/Live/分享/数据库零改动

## 需求

导出 PDF 时二选一:**标准 PDF**(默认,现状不变)/ **印刷版 PDF(含 3mm 出血)**。
选印刷版时 UI 说明:「四边各加 3mm 出血,供印刷厂裁切;页面尺寸相当于 216×303mm」。

## 已定决策

| 议题 | 决策 |
|---|---|
| 出血值 | 固定 3mm(行业标准),本轮不做可调 |
| 出血内容生成 | **边缘延伸**:最外圈 1px 像素拉伸填满出血条带,页内容零位移零缩放 |
| 裁切角线 | 不画,纯出血尺寸(数码印刷/照片书厂收件惯例) |
| 默认档位 | 默认无出血 |
| 双宽页 | 照旧拆装订两半,每半各自四边延伸(书脊侧也延伸,印厂拼版通用) |
| 封面/封尾 | 与内页同规则;硬壳包边(15-20mm)不在本轮 |

## 实现

### 渲染(`apps/web/src/lib/pdf/render-raster.ts` 一族)

- `RasterPdfOptions` 加 `bleedMm?: number`(缺省 0)。
- 换算:页面 794px ↔ A4 210mm → 1mm = 794/210 px;出血 3mm ≈ 11.34 CSS px,
  画布层为 `bleedMm × (794/210) × scale` 像素(四舍五入)。
- 新纯函数 `extendCanvasEdges(canvas, bleedPx)`(独立文件 `apps/web/src/lib/pdf/extend-canvas-edges.ts`):
  开 (W+2B)×(H+2B) 画布,中间贴原图;四边用 drawImage 把最外 1px 行/列拉伸成 B 宽条带;
  四角用角落 1px 像素填充。每页(含拆半后的双宽半页)截图完成后过它。
- jsPDF 页面尺寸从 `[PAGE.width, PAGE.height]` 变 `[794+2b, 1123+2b]`(b 为 CSS px 出血),
  图片铺满整页;等比物理尺寸即 216×303mm。
- `bleedMm` 为 0 时完全走原路径,输出逐字节不变(回归底线)。

### 交互(双端)

- 桌面(EditorPort 导出弹窗)与移动(`ExportModals`)的 PDF 项下加二选一,默认「标准 PDF」;
  选「印刷版 PDF」时显示上述说明文案。确认后把 `bleedMm: 3` 传入既有导出调用。
- 文案中英双语,沿用各端现有弹窗视觉与 i18n 机制。

## 测试

- `extendCanvasEdges` 尺寸与几何单测(输出画布尺寸、原图位置偏移 = B)。
- jsPDF 页面尺寸换算单测(3mm → px 的换算函数独立导出)。
- 真渲染对照:仓里既有导出取证法(esbuild 打包真管线 + playwright)跑一页含出血导出,
  断言出血条颜色 == 相邻边缘像素、整页尺寸 = (794+2b)×(1123+2b)×scale。
- 接线守卫:两个选项存在、默认无出血、只有印刷版传 `bleedMm: 3`。

## 明确不做(YAGNI)

- 出血值可调 / 安全线预览(编辑器参考线是另一个需求)
- 裁切角线、TrimBox/BleedBox 元数据
- 硬壳封面包边
- 单页图片导出的出血
