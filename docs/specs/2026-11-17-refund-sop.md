# 退款处置 SOP（客服执行手册）

> 依据:`apps/web/src/messages/marketing/zh.ts` 的 `refund` 段（页面 `/refund`）与服务条款 §7。
> **本文不能和页面说法冲突。** 页面是给用户看的承诺,本文是内部怎么执行的;两者不一致时,
> 先按页面执行,再回来改页面 —— 不要让用户读到一套、被告知另一套。
>
> 渠道现状:线上收款通道尚未开通(见 issue #376),所以现在收到的退款申请应当只有
> 「历史订单」与「误扣」两类。真正开通后,本 SOP 第 4 节的路径才逐条生效。

## 1. 判定表（先看这张）

| 用户情况 | 结论 | 依据 |
|---|---|---|
| 该笔订单积分**完全未使用**（没发起过生成、没导出、没分享） | **全额退** | 退款政策 §2 |
| 同一订单**重复扣款**,或系统错误**多扣** | **全额退**（退重复/多扣部分） | 退款政策 §2 |
| 因**我们的故障**,购买后积分在合理时间内完全无法使用 | **全额退** | 退款政策 §2 |
| 积分已因**排版成功**而消耗（含用户不满意排版结果） | **不退** | 退款政策 §3 |
| 已用该积分**导出或分享**过成册 | **不退** | 退款政策 §3 |
| 因**违反服务条款**被限制/终止账号 | **不退**,法律另有规定除外 | 退款政策 §3 |
| **活动/邀请/补偿赠送**的积分 | **不退** | 退款政策 §3 |
| 生成失败,积分被冻结 | **不是退款** —— 冻结的积分自动释放,余额不减少 | 退款政策 §4 |
| 用户声称「扣了积分但没生成」 | 先查流水,核实后**补回积分**,不走退款 | 退款政策 §4 |

**不做的事**:不按「未使用张数」折算退款 —— 退款按整笔订单处理。不自设时间窗口(不写「7 天内」),
不承诺固定 SLA(不写「3 个工作日」),统一说「尽快回复」。

## 2. 收到申请后的五步

1. **收集**:让用户提供购买邮箱、下单时间、订单金额、积分包规格。（页面 §6 已经列出这四项,
   缺项时按这四项追问,不要再加别的）
2. **定位订单**:按邮箱 + 时间在支付渠道后台找到交易号;核对金额与积分包是否与用户所述一致。
3. **查使用情况**:在积分流水中确认该笔订单的积分是否被消耗（`GENERATION_SETTLE` 记在关联相册上）。
   - 未消耗 → 走退款
   - 已消耗 → 按第 1 节说明「不退」,并把消耗对应到具体相册/生成记录给用户看
4. **判定并回复**:用第 4 节的模板。判定为不退时,必须说清楚为什么,并给出依据(条款/政策条目)。
5. **执行退款**:按第 4 节路径原路退回;把结果、交易号、处理时间记进 issue,便于对账。

## 3. 边界情况

| 情况 | 处理 |
|---|---|
| 用户已向发卡行发起拒付(chargeback) | 不重复退款;整理完整交易凭证(交易号、时间、金额、积分发放记录)应对争议;同时告知用户我们仍愿意先直接解决 |
| 同一用户反复申请同一笔订单 | 只按第一次判定执行;第二次回复引用第一次的处理记录 |
| 跨境支付的汇兑差异 | 由发卡行决定,不由我们收取;能退的只有我们实收金额 |
| 欧盟/英国用户主张撤回权 | 已明确同意「数字内容一经开始提供即失去撤回权」且已开始提供的,不适用;尚未开始提供的,依法可退 |
| 金额与页面标价不一致 | 先按用户实付金额退,再作为缺陷单独立项(不要用「价格调整」当理由拒退) |

## 4. 退款执行路径

| 渠道 | 路径 | 到账时间（页面已写明） |
|---|---|---|
| 银行卡（海外） | 渠道后台发起退款 → 原卡 | 5–10 个工作日 |
| 微信支付 | 商户后台原路退回 | 通常更快 |
| 支付宝 | 商户后台原路退回（`alipay.trade.refund`） | 通常更快 |
| 积分调整（非退款） | 后台调整积分并留备注 | 立即 |

**当前实际状态**:三条渠道均未开通收款,所以第 1–3 行暂无适用订单。

## 5. 回复模板

**全额退**
> 已核实:这笔订单（¥/US$ X,YY 积分包,下单时间 Z）的积分尚未使用,符合退款条件。
> 我们已发起原路退款,预计 5–10 个工作日到账(具体取决于发卡行)。退款完成后这笔积分会从账户中扣回。

**不退（已消耗）**
> 这笔订单的积分已经用于《相册名》的排版,已于 YYYY-MM-DD 扣除。按退款政策 §3,
> 已因排版成功消耗的积分不支持退款,包括对排版结果不满意的情形。
> 如果你认为这是误扣(即积分被扣但成册没有生成),请回复我们,核实后会补回积分。

**生成失败（不是退款）**
> 这次生成失败,冻结的积分已经自动释放,你的余额没有减少,不需要申请退款。
> 如果余额显示仍有缺口,请把订单信息和相册名发给我们,核实后补回。

**重复扣款**
> 已核实这笔订单被扣了两次。重复的部分我们已发起原路退款,预计 5–10 个工作日到账。

## 6. 不能承诺的话

- 不承诺具体到账日期(渠道决定,页面只写「通常 5–10 个工作日」)
- 不承诺「一定退」(先核实用量,再判定)
- 不说「公司规定不退」这类无依据的说法;只引用政策条目
- 不承诺补偿以外的权益(优惠券、赠品)
