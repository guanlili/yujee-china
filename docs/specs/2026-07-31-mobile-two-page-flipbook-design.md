# 移动端固定双页翻书预览设计

## 目标

截图所示的移动端相册预览只保留双页书册模式，移除 1 / 2 / 4 页密度切换；增强纸张投影与翻书效果。封面、封尾使用与正文相同的单页尺寸，静止时居中；进入或离开正文时，整本书平移半页，同时让封皮绕书脊旋转，保持单页与双页形态之间的视觉连续性。

桌面端预览不在本次范围内。

## 交互

- 浏览态固定为一个跨页一屏，不再提供密度切换按钮。
- 正文按左右双页展示，横向滑动按跨页导航。
- 正文前进时右页向左翻，返回时左页向右翻。
- 封面、封尾静止时均以单页尺寸居中。
- 封面进入正文时向左打开；从正文返回封面时播放反向闭合动画。
- 正文进入封尾时向右闭合；从封尾返回正文时播放反向打开动画。
- 缩略条按屏分组：正文一个跨页一格，封面和封尾各占一个单页格。
- 用户启用“减少动态效果”时直接切换页面，不播放 3D 翻页。
- 点击页面进入编辑态的既有行为保持不变。

## 尺寸与布局

- 所有页面共享同一个物理单页尺寸。
- 先按可用画板空间计算双页书册盒子，再以其宽度的一半作为单页宽度。
- 所有状态始终使用完整双页书盒作为统一坐标系，单页纸张仍只占书盒的一半。
- 封面位于书盒右半页，静止时书盒整体向左平移四分之一书盒宽，使封面视觉居中。
- 封尾位于书盒左半页，静止时书盒整体向右平移四分之一书盒宽，使封尾视觉居中。
- 打开或闭合过程中，书盒在静止偏移和零偏移之间连续运动，因此旋转轴会从单页边缘自然移动到最终双页中缝，不发生位置跳变。
- 双宽模板仍占满完整双页盒子，不增加中缝。
- 奇数落单的普通正文跨页保留现有空白半页语义，不误判为封面或封尾。

## 视觉

- 静止书册使用两层投影：贴近纸面的接触阴影与更柔和的环境阴影。
- 页面外缘增加轻微高光，保持纸张边界清晰。
- 普通双页继续显示书脊渐变阴影。
- 翻动纸片保留正反面，并随翻转方向叠加靠书脊的动态明暗。
- 投影只作用于预览容器，不改变页面 HTML、导出结果或持久化数据。

## 实现边界

- 修改移动端 React 预览树 `MobileEditor` 及其移动端翻页纯函数和样式。
- 不引入第三方翻书依赖。
- 不修改桌面 `FlipBook`。
- 不修改页面数据结构、模板、后端接口或数据库。
- 保留共享的 1 / 2 / 4 密度类型和旧逻辑，避免影响仍可能使用它们的其他代码；新的移动端预览入口固定传入密度 2。

## 状态与动画

- 正文到正文继续使用现有半页叶片动画。
- 封面打开：书盒从 `translateX(-25%)` 移到 `0`，右半页封面从 `rotateY(0)` 转到 `rotateY(-180deg)`。
- 封面闭合：书盒从 `0` 移到 `translateX(-25%)`，右半页封面从 `rotateY(-180deg)` 回到 `rotateY(0)`。
- 封尾闭合：书盒从 `0` 移到 `translateX(25%)`，左半页封尾从 `rotateY(180deg)` 回到 `rotateY(0)`。
- 封尾打开：书盒从 `translateX(25%)` 移到 `0`，左半页封尾从 `rotateY(0)` 转到 `rotateY(180deg)`。
- 四种边缘动画都使用同一完整双页坐标系，正文作为底层；不再在动画开始时把半宽容器瞬间扩成双宽容器。
- 正文底层、书脊和双页投影在动画约 30% 处开始渐入；封皮自身投影随旋转保留，避免空白半边提前暴露。
- 边缘动画时长从 900ms 缩短为 700ms；正文到正文仍沿用现有 900ms 时长。
- 不满足受支持的相邻形状、动画进行中、已经到书边或减少动态效果开启时，保持安全的直接切换。
- 翻页开始时缩略条高亮立即移动到目标跨页，动画结束后提交新的浏览游标。

## 测试与验收

- 纯函数测试锁定固定双页分屏、四种边缘动画资格、书盒位移和封皮旋转几何。
- 组件结构测试锁定密度按钮移除、固定双页调用，以及封面/封尾始终使用统一双页坐标系。
- 样式测试锁定静止投影、纸边高光、书脊和翻动纸片阴影。
- 运行移动端相关测试、Web 全量测试和 Web typecheck。
- 在本地移动端预览中检查封面、正文、封尾三个状态及四种边缘动画，确认动画开始和结束均无水平跳变。
