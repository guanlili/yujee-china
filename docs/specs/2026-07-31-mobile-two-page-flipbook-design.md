# 移动端固定双页翻书预览设计

## 目标

截图所示的移动端相册预览只保留双页书册模式，移除 1 / 2 / 4 页密度切换；增强纸张投影与翻书效果，并让封面、封尾使用与正文相同的单页尺寸居中显示。

桌面端预览不在本次范围内。

## 交互

- 浏览态固定为一个跨页一屏，不再提供密度切换按钮。
- 正文按左右双页展示，横向滑动按跨页导航。
- 正文前进时右页向左翻，返回时左页向右翻。
- 封面静止时以单页尺寸居中；进入正文时封面向左翻开。
- 封尾静止时以单页尺寸居中；从封尾返回正文时封尾向右翻开。
- 缩略条按屏分组：正文一个跨页一格，封面和封尾各占一个单页格。
- 用户启用“减少动态效果”时直接切换页面，不播放 3D 翻页。
- 点击页面进入编辑态的既有行为保持不变。

## 尺寸与布局

- 所有页面共享同一个物理单页尺寸。
- 先按可用画板空间计算双页书册盒子，再以其宽度的一半作为单页宽度。
- 正文使用完整双页盒子；封面、封尾使用半宽盒子并在画板中居中。
- 双宽模板仍占满完整双页盒子，不增加中缝。
- 奇数落单的普通正文跨页保留现有空白半页语义，不误判为封面或封尾。

## 视觉

- 静止书册使用两层投影：贴近纸面的接触阴影与更柔和的环境阴影。
- 页面外缘增加轻微高光，保持纸张边界清晰。
- 普通双页继续显示书脊渐变阴影。
- 翻动纸片保留正反面，并随翻转方向叠加靠书脊的动态明暗。
- 投影只作用于预览容器，不改变页面 HTML、导出结果或持久化数据。

## 实现边界

- 修改移动端 React 预览树 `MobileEditor` 及其移动端翻页纯函数和样式。
- 不引入第三方翻书依赖。
- 不修改桌面 `FlipBook`。
- 不修改页面数据结构、模板、后端接口或数据库。
- 保留共享的 1 / 2 / 4 密度类型和旧逻辑，避免影响仍可能使用它们的其他代码；新的移动端预览入口固定传入密度 2。

## 状态与动画

- 正文到正文继续使用现有半页叶片动画。
- 封面到正文使用单页叶片：封面为正面，绕左侧书脊向左旋转，正文作为底层。
- 封尾返回正文使用单页叶片：封尾为正面，绕右侧书脊向右旋转，上一正文跨页作为底层。
- 不满足受支持的相邻形状、动画进行中、已经到书边或减少动态效果开启时，保持安全的直接切换。
- 翻页开始时缩略条高亮立即移动到目标跨页，动画结束后提交新的浏览游标。

## 测试与验收

- 纯函数测试锁定固定双页分屏、封面向左和封尾向右的动画资格及几何。
- 组件结构测试锁定密度按钮移除、固定双页调用、封面/封尾使用统一单页盒子。
- 样式测试锁定静止投影、纸边高光、书脊和翻动纸片阴影。
- 运行移动端相关测试、Web 全量测试和 Web typecheck。
- 在本地移动端预览中检查封面、正文、封尾三个状态及双向滑动。
