# 备案主体变更材料清单（企业主体 · 支付宝接入前置）

> 目的:把 `outman.press` 的备案主体从个人变更为 **北京知景方略信息科技有限责任公司**,
> 使支付宝开放平台的「账号主体 = 备案主体」条件成立。
>
> 现状:备案号 `京ICP备2022033467号-4`,`apps/web/src/config/beian.ts` 注释写明个人主体。
> 域名 `outman.press` 的实名持有者未确认 —— **先查这一项**,它决定下面走哪条路。
>
> 本清单是准备材料的脚手架,不替代接入商的核验口径。任何一项拿不准,以接入商(腾讯云/阿里云)
> 备案客服的答复为准;本文不写「已获得批准」之类的结论,只列要交什么、从哪里拿。

## 0. 先做三项确认（决定路线）

| # | 要确认的事 | 怎么确认 | 结果影响 |
|---|---|---|---|
| 0.1 | `outman.press` 域名实名持有者是谁 | 腾讯云/阿里云控制台的「域名信息」;域名在谁名下就由谁过户 | 持有者 ≠ 备案主体 → 变更前先过户 |
| 0.2 | 本省是否支持「个人 → 企业」主办单位变更 | 问接入商备案客服,明确问:该省份是否支持已有备案的主体变更,还是必须注销后重报 | 支持 → 走 A1;不支持 → 走 A2 |
| 0.3 | 公司营业执照注册地省份 | 营业执照 | 决定受理省份与是否需要当地人脸核验 |

**已知的现实情况**:多数省份不支持个人→企业的主办单位变更,需要「先注销个人备案,再以企业新增
备案」。注销到新增之间网站会处于无备案状态,期间过不了备案核验 —— 需要排期,不能在推支付宝
签约的那几天做。

## 1. 主体材料（企业）

| # | 材料 | 说明 | 从哪拿 |
|---|---|---|---|
| 1.1 | 营业执照原件彩色扫描/拍照 | 需在有效期内,统一社会信用代码清晰 | 公司存档 / 电子营业执照小程序 |
| 1.2 | 法定代表人身份证正反面 | 与营业执照上的法人一致 | 本人 |
| 1.3 | 法定代表人手机号 + 可接收短信 | 用于备案系统核验与人脸识别 | 本人 |
| 1.4 | 企业备案授权书（如非法人本人办理） | 需盖公章,写明被授权人姓名、身份证号 | 自制模板 + 公章 |
| 1.5 | 被授权人身份证正反面 + 手机号 | 仅在 1.4 成立时需要 | 被授权人 |
| 1.6 | 公章 | 部分环节需现场盖章上传 | 公司 |

## 2. 域名与接入材料

| # | 材料 | 说明 | 从哪拿 |
|---|---|---|---|
| 2.1 | 域名证书 | 证明 `outman.press` 的持有者;变更备案要求持有者与备案主体一致 | 域名控制台「域名证书下载」 |
| 2.2 | 域名过户记录（如 0.1 不一致） | 先过户到公司名下,再办备案 | 域名控制台 |

## 3. 与支付平台的衔接（备案通过后）

| # | 事项 | 说明 |
|---|---|---|
| 3.1 | 支付宝开放平台企业账号 | 用营业执照 + 法人身份证注册,**账号主体必须是公司** |
| 3.2 | 账号主体与备案主体一致性 | 一致 → 直过;不一致 → 需授权函,且「个人向企业授权」通常不被认可 |
| 3.3 | 电脑网站支付签约 | 类目按「数字内容 / 数字娱乐」报,费率 0.6%（数娱类目可能 1.2%） |
| 3.4 | 对公账户 | 结算账户须为公司对公户 |
| 3.5 | 应用与密钥 | `ALIPAY_APP_ID` / `ALIPAY_PRIVATE_KEY` / `ALIPAY_PUBLIC_KEY` / `ALIPAY_SELLER_ID` 填入部署环境 |

**不要做的事**:不改 `beian.ts` 里的备案号去「假装」已经是企业备案;代码改动不构成备案主体变更。

## 4. 时间与风险

| 环节 | 大致耗时 | 风险 |
|---|---|---|
| 域名过户 | 1–3 工作日 | 过户期间域名解析一般不受影响,但实名审核可能触发暂停解析 |
| 个人备案注销 | 1–3 工作日 | 注销后网站处于无备案状态 |
| 企业新增备案 | 7–20 工作日 | 各省审核差异大;期间不得对外提供未备案服务 |
| 支付宝签约 | 1–7 工作日 | 类目审核可能要求补充材料 |

**排期建议**:备案这一段不要和任何推广/上线动作重叠。挂起项
[#376](https://github.com/guanlili/yujee-china/issues/376) 的启动条件就是「备案后台确认主体已是公司」
或「完成变更 + 域名过户」。
