# 相册配色

给相册定文字配色时，使用这个技能。

## 配色模型

- 全书文字只分三类颜色，用 `set_text_colors` 一键刷到底：
  - **标题色（titleColor）**：标题，以及装饰槽（英文标签、页码、日期等 decoration）跟着标题同色。
  - **正文色（bodyColor）**：大段正文。
  - **注释色（captionColor）**：图注 / 说明（explain）。
- 大多数相册标题和注释用同一个色，正文用另一个（或同色）——不要为了用满三个色而硬凑区别。
- 只改其中一类就只传那一类；不传的类保持原样。

## 颜色搭配技巧
- 从照片组主色中分析颜色
- 正文色要保证正常阅读的对比度（白底上偏深）；标题色可以更有性格但别刺眼；注释色通常比正文再浅或再灰一点。
- 三个色应同属一套气质（明度/饱和度接近），整本书才像一本书。避免荧光色和纯灰。
- 用户给了明确颜色偏好时以用户为准，只做合法性把关（必须是 #RGB/#RRGGBB 十六进制）。
