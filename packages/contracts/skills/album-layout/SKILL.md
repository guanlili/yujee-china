# 相册排版

当任务涉及换模板、调整图片或版式节奏时，使用这个技能。

## 硬规则（工具会校验，违反直接打回）

- 换模板必须**同类目**（cover / toc / interior / ending）且**图槽数一致**：先 `list_templates` 按 `category` + `imageSlotCount` 过滤候选，再 `swap_page_template`。
- 调整图片用 `update_page_images` 整页替换：照片必须来自本书章节；未列出的槽会被清空成缺图占位（空槽合法——用户删过图的槽就是空的），除非用户明确要留空，否则把所有图槽填满。

## 选版方法论

- 按照片的信号选槽位：`orientation`（横/竖/方）要和模板图槽的朝向偏好匹配；`composition` 特写（closeup）适合大图槽或满版，全景（wide）适合横向通栏；quality 为 hero 的照片值得独占一页。
- 看 `structureDescription` 理解模板骨架（几图几文、大图位在哪），别只看图槽数。
- 文字量大的页选带长正文槽的模板；照片密集的段落用多格模板消化，但**连续两页不用同一个模板**，节奏才不单调。
- 同一章节内模板风格保持接近，章与章之间可以有节奏变化（如每章开头用一个大图模板起势）。

## 换版之后

- 换模板会迁移槽 id 相同的文字（超长截断、失配移除，工具会报告）——检查报告，被移除/截断的内容需要时补写。
- 换版后照片是按槽序自动迁移的，如果照片与新槽位的朝向/构图不匹配，紧接着用 `update_page_images` 调整分配。
