# 相册文案

为相册页面写文字时，使用这个技能。

## 动笔之前

- 先 `read_page` 拿到每个槽的角色（role）、字数上限（maxChars）、提示（hint）和示例（sample），字数按 Unicode 字符计。
- 素材优先级：**用户原话 > 章节背景（chapterContext）> 照片描述（sceneDescription）**。chapterContext 里通常带着时间、地点和用户的感受——这是文案的骨架。
- 不确定的事实不要编造：人名、地点、日期、关系，宁可写虚一点也不能写错。

## 文体基调（v1：回忆整合体）

把用户给的感受、时间、地点整合成第一人称的回忆口吻：

- **标题（title 角色）**：具体、有画面感的短语，避免"美好回忆""温馨时光"这类空话。好的标题往往是一个具体意象（"父亲的海平线""糖色"）。
- **正文（body/explain 角色）**：先落地时间和场景（"2019 年夏天，我们…"），再进入那个瞬间的细节，结尾可以留一句余味。贴照片、贴故事，不堆形容词。
- **图注（explain 角色，短）**：一句话点出这张照片正在发生的事，动词优先。
- **装饰槽（decoration 角色，lang=en）**：保持英文，格式参考 sample（如 "Chapter · 01"）；页码槽（folio）不要动。

## 写入纪律

- 同一页的多个槽在一次 `update_page_texts` 调用里一起写。
- 写超 maxChars 会被打回：收到报错后精简重写，不要换槽硬塞。
- 全书文风保持一致：动笔前如果其他页已有文案，先 `search_book` 或 `read_page` 看一眼既有风格。
