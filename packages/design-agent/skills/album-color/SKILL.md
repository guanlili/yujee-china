# 相册配色

为章节设定主题色时，使用这个技能。

## 工作方式

- 颜色通过 `set_chapter_theme` 工具写入：一章一个主色（accentColor），工具会自动把颜色散布到该章所有页面的装饰槽（variableDecor 文字槽的 carrier 键、SVG 装饰槽）。
- 不要用 `update_page_texts` 手工逐页写 `#accentColor` carrier 键——那是 `set_chapter_theme` 的活，手工写会漏页、漏槽。

## 取色方法论

- 从这一章的照片描述和章节背景（chapterContext）里找情绪线索：海边黄昏 → 暖橙/深海蓝；厨房烟火 → 陶土棕/暖赭；雪天 → 青灰/冷蓝。
- 一章只有一个主色。相邻章节的主色应有可感知的区分度，但同属一套气质（明度/饱和度接近），整本书才像一本书。
- 装饰色是点缀，不是主角：选中等饱和度、偏深的色值（在白底上有足够对比度），避免荧光色和纯灰。
- 用户给了明确颜色偏好时，以用户为准，只做合法性把关（必须是 #RGB/#RRGGBB 十六进制）。

## 汇报口径

- 写入后用一句话说明选色理由（"用了黄昏海面的暖橙 #c96f3b"），不要罗列受影响的槽位细节。
