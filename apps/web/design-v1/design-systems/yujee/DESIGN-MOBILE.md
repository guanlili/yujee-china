# Yujee — 小程序 / 移动端设计规范

> **爱你老己，生命里的重要时刻留下来。**
>
> 基于 Yujee Web 端规范的移动端适配层。品牌色、渐变、字体家族不变，
> 尺寸体系、间距节奏、交互模型针对微信小程序重新定义。

---

## 1. 尺寸体系

### 设计稿基准
- **设计稿宽度**: 750rpx（= 375pt @2x）
- **单位**: rpx（750rpx = 设备屏幕宽度）
- **换算**: 1px(Web) ≈ 2rpx

### 安全区域

| 区域 | 高度 | 说明 |
|------|------|------|
| **状态栏** | 机型变量（约 44pt / 88rpx） | 通过 `wx.getSystemInfo` 获取 |
| **导航栏** | 88rpx（44pt） | 自定义导航需计算 statusBarHeight + 44pt |
| **胶囊按钮** | 右上角微信原生，宽 174rpx | 自定义导航内容不可与其重叠 |
| **底部安全区** | 68rpx（34pt） | iPhone Home Indicator |
| **TabBar** | 100rpx（不含安全区） | 含安全区约 168rpx |

### 最小触控区
- **最小可点击区域**: 88 × 88rpx（44 × 44pt）
- 即使视觉尺寸小于此值，点击热区必须达到 88rpx

## 2. 字号阶梯

| 角色 | 尺寸 (rpx) | 尺寸 (pt) | Weight | 用途 |
|------|-----------|-----------|--------|------|
| **大标题** | 56rpx | 28pt | 700 | 页面主标题 |
| **标题** | 40rpx | 20pt | 700 | Section 标题 |
| **小标题** | 34rpx | 17pt | 600 | 卡片标题、列表标题 |
| **正文** | 30rpx | 15pt | 400 | 主体内容 |
| **辅助文本** | 26rpx | 13pt | 400 | 描述、说明 |
| **标注** | 24rpx | 12pt | 500 | 时间戳、标签、meta |
| **极小** | 22rpx | 11pt | 500 | Badge、角标 |

### 行高
- 标题：1.2
- 正文：1.6
- 辅助/标注：1.4

### 字间距
- 标题 ≥ 40rpx 时：letter-spacing: -0.01em
- 正文及以下：默认

|-------|----------|---------|------|
| `--sp-1` | 4rpx | 2pt | 极细间距 |
| `--sp-2` | 8rpx | 4pt | 组件内紧凑间距 |
| `--sp-3` | 12rpx | 6pt | 图标与文字 |
| `--sp-4` | 16rpx | 8pt | 列表项内间距 |
| `--sp-5` | 20rpx | 10pt | 卡片内元素间距 |
| `--sp-6` | 24rpx | 12pt | 组件间间距 |
| `--sp-8` | 32rpx | 16pt | 段落间、模块内间距 |
| `--sp-10` | 40rpx | 20pt | Section 间小间距 |
| `--sp-12` | 48rpx | 24pt | Section 间标准间距 |
| `--sp-16` | 64rpx | 32pt | 大 Section 间距 |
| `--sp-20` | 80rpx | 40pt | 页面顶/底留白 |

### 页面级间距

| 区域 | 值 |
|------|-----|
| **页面水平边距** | 32rpx（16pt）|
| **卡片内边距** | 32rpx（16pt）|
| **列表项内边距** | 32rpx 水平，24rpx 垂直 |
| **Section 间距** | 48rpx（24pt）|
| **页面顶部留白** | 32rpx（安全区之下）|
| **页面底部留白** | 80rpx（TabBar 之上）|

### 间距规则
- 模块之间用 48rpx 空白分隔，不用分割线
- 同一模块内元素间距 16–24rpx
- 列表相邻项之间 24rpx（如需分隔用 1px 线 + 左侧 32rpx 缩进）
- 卡片与卡片之间 24rpx

## 4. 按钮

### 尺寸规格

小程序只使用两种按钮尺寸（不需要 Large/Medium — 移动端屏幕小，大按钮浪费空间）：

| 类型 | 高度 | 内边距 | 字号 | 圆角 | 用途 |
|------|------|--------|------|------|------|
| **Small** | 64rpx（32pt） | 0 24rpx | 26rpx / 500 | pill（9999px） | 常规操作按钮 |
| **Mini** | 56rpx（28pt） | 0 20rpx | 24rpx / 500 | pill | 辅助操作、弹窗内按钮 |

### 按钮类型（继承 Web 端）

**Primary（主按钮）**
- 黑色背景 `#111`，白色文字
- pill 全圆角
- **`.m-btn-glow` 包裹容器** + `::after` `linear-gradient(90deg, #13B8A6, #8C5EF4, #DAF45E)` + `filter: blur(8px)` + `opacity: 0.5`
- **按压态（无 hover）**: `scale(0.97)` + 光晕收缩变淡

**Brand（品牌按钮）**
- 黑色背景 `#111`，白色文字
- pill 全圆角
- **`.m-btn-glow .m-btn-glow-brand` 包裹容器** + `::after` `linear-gradient` + `filter: blur(10px)` + `opacity: 0.65`（比 Primary 更强）
- **按压态**: `scale(0.97)` + 光晕收缩变淡
- 一页最多 1 个

**Outline（描边按钮）**
- 透明背景，1px 边框 `#111`
- pill 全圆角
- **按压态**: 黑底白字反转

**Ghost（幽灵按钮）**
- 无边框无背景，文字 + 箭头 →
- **按压态**: 文字变灰 `#888`

### 使用原则
- 小程序上大多数按钮用 **Outline**（描边） — 不要满屏黑色填充按钮
- **Primary**（黑底白字）只用于确认性操作（提交、确认、保存）
- **Brand**（黑底白字 + 渐变投影）每页最多 1 个，仅用于最重要的品牌 CTA
- **Ghost** 用于链接式操作（更多 →、跳过 →）

### 按钮间距
- 并排按钮间距：16rpx
- 底部固定按钮距屏幕底：32rpx + 安全区
- 按钮组（2 个）：主按钮占 2/3 宽度，辅按钮占 1/3

### 按钮状态（移动端专属）
- **默认态**: 正常显示
- **按压态 (pressed)**: 0.97 缩放 + 背景加深（取代 Web 的 hover）
- **禁用态**: opacity 0.4，不可点击
- **加载态**: 文字替换为 loading 动画（3 点跳动），按钮不可重复点击

## 8. 导航

### 自定义导航栏
- 高度：状态栏 + 88rpx
- 背景：`#ffffff` 或透明（滚动后渐显白色）
- 左侧：返回箭头 44rpx 热区
- 中间：页面标题 34rpx / weight 600
- 右侧：预留胶囊按钮宽度（174rpx + 16rpx）不放内容

### TabBar
- 高度：100rpx + 底部安全区
- 背景：`#ffffff`
- 分隔：顶部 1px 线 `#e0e0e0`
- 图标：48rpx，间距 4rpx 到文字
- 文字：22rpx / weight 500
- 选中态：`#111`（非选中 `#aaa`）
- Tab 数量：2–5 个

## 10. 弹窗 / 浮层

### 半屏弹窗（Bottom Sheet）
- 从底部滑出，圆角 24rpx（仅顶部）
- 顶部拖拽条：48rpx × 8rpx，`#e0e0e0`，居中，圆角 pill
- 内边距：32rpx 水平，24rpx 顶部
- 背景：`#ffffff`
- 遮罩：rgba(0,0,0,0.4)

### ActionSheet（操作列表）
- 底部弹出，选项高度 112rpx
- 选项间 1px 分隔线
- 取消按钮与选项之间 16rpx 间隔
- 全部 pill 圆角容器（24rpx）

### Toast
- 居中显示，黑底白字
- 内边距 24rpx 40rpx
- 圆角 pill
- 自动消失 1.5s

## 11. 品牌渐变（移动端适配）

- 弥散光晕面积缩小（最大不超过屏幕宽度 60%）
- blur 值 60–80rpx（比 Web 端小）
- opacity 0.3–0.5（比 Web 端略低，小屏上色块太亮会压过内容）
- 仍然只在关键品牌时刻出现，一页最多一处
- **所有黑色按钮（Primary + Brand）通过 `.m-btn-glow` 包裹容器的 `::after` 渲染横向 `linear-gradient` 光晕**
  - `linear-gradient(90deg, #13B8A6, #8C5EF4, #DAF45E)` — 蓝绿→紫→黄绿真横向渐变
  - Primary: blur 8px，opacity 0.5
  - Brand: blur 10px，opacity 0.65

## 12. 反模式（移动端）

- ❌ 不要依赖 hover 态 — 移动端没有 hover，用按压态替代
- ❌ 不要做小于 88rpx 的点击热区
- ❌ 不要在导航栏右侧放内容 — 会和微信胶囊按钮冲突
- ❌ 不要用纯白背景做页面底色 — 保持 `#f5f5f5` 淡灰，卡片白色分层
- ❌ 不要做超过 5 层的页面栈 — 小程序有限制
- ❌ 不要用 Web 端的 select 下拉 — 用 Picker 滚轮
- ❌ 不要用居中弹窗 — 用底部半屏弹窗
- ❌ 不要在全局使用渐变 — 移动端屏幕小，品牌光晕只在首页/关键页出现一次
- ❌ 不要用方角 — 所有按钮/输入框 pill，卡片 24rpx
