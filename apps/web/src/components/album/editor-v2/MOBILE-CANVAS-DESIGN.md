# 移动端画板交互重构 · 设计说明

> Issue #304 · 分支 `feat/mobile-canvas-interaction`
> 状态：设计已与用户确认，待落实现计划。本文件是实现的依据，不是像素稿。

## 背景

桌面画板（2026-07-15 拍板）是**无限画布**：所有跨页平铺进 `#ovGrid`，双指捏合 0.2–3 倍、单指拖平移，编辑就地发生，缩放永不切视图。这套直接搬到手机（现状 `@media (max-width:767px)` 那一大段）后水土不服：

1. **可视画布只剩四成** —— 52px 顶栏 + 46vh 聊天面板 + `book-stage` 硬编码 `padding-bottom:220px`；且 220px 是死值，聊天面板拖高/收起画布都不知道。
2. **画板模式不知道自己在第几页** —— 翻页 pill 被 `.overview-on .zoom-ctrl{display:none}` 整条隐藏，无限画布上无页码/章节/进度。
3. **六层浮层各占各的** —— 聊天 z80 / 视图 dock z88 / 工具条 z96 / 图片浮条 z110 / 取色器 z130 / mes z140，没有统一底部空间账本，mes 一开 66vh 常盖住正在改的内容。
4. **图片编辑还是桌面尺寸** —— 文字/页面进了 `mes`，唯独图片留在 96px 滑块的小胶囊上，拇指调不准。
5. **顶栏是桌面版压扁的** —— 返回/logo/相册名/保存/分享/实心黑导出/头像七样挤在 52px 里，份量最重的黑 pill 给了低频的导出。

**保留**：已做过那轮 `mes` 优化（字号步进胶囊、8 常用色漏出、字体 chips、textarea 16px 防 iOS 聚焦缩放）有效，继续用其交互语言。

## 双态模型

手机画板只有两个态，之间只有"点进去 / 退出来"，无中间态、无"缩放到多少倍算哪个态"的模糊地带。

### 浏览态 —— 书居中，画布不滚

- 一屏一个视图单位，**居中浮在垫底背景（`#boardBg`）上**，四周露背景。
- **画布不做上下滚动**（手机上"滚动的画布"和"滚动的页面内容"永远抢手指）。
- 换页：底部**缩略条**横滑点选，或画布上**左右滑**。
- ~~缩略条末尾 `+` 新增页面~~ **【本次搁置】** 编辑器无现成加页通道，实现它需动 PATCH 通道+模板渲染（本 spec 明令不改）。新增页作为独立后续功能另开分支，本次不做。缩略条只做跳屏导航。
- **一屏几页（密度 1 / 2 / 4）**：左下角一个小图标钮，钮上写当前档数字，点一下循环 1→2→4→1。含义：1=单页看细节，2=跨页并排还原对页关系（默认），4=2×2 快速找位置。密度不是 CSS 缩放，是**换列数 + 按新格子宽度重绘**。
- **换画板背景**：左下角另一个小图标进设置，纯色 / 预设 / 上传三档照旧，走现有 `applyBoardBackground`，功能不动。

### 编辑态 —— 先选中，再编辑

- 点某页 → 那页放大到满屏（**按新尺寸重绘，不是 transform 拉伸**），底部换成一级栏。
- 翻页靠**左右滑**，不留缩略条（高度全给页面），位置条显示 `7 / 24`。
- 底部**一级栏三格常驻**：背景 · 图片 · 文字。都是页面级入口，不用先选中。这里的「背景」**只管当前页的页面底色**（复用现有 Page background 弹窗：Palette / Picker 两 tab），不含画板背景。（~~删除~~ **【本次搁置】**：编辑器无删页后端通道，实现需新增 API + 页索引重排，超本次交互重构范围。删页与加页同为结构操作，作为后续功能另开分支。）
- **图片 / 文字都是两步：先选中，再编辑**（不整页一起改）：
  - 点「图片」→ 页面上照片亮虚线框 → 点中一张 → 底部升起只属于这张的工具：缩放滑块（全宽 22px 触点）· 换照片 · 铺满 · 复位 · 滤镜；拖图改构图。
  - 点「文字」→ 文字块亮虚线框 → 点中一段 → 内容 · 字号 · 字体 · 颜色 · 对齐 · 粗斜（沿用 `mes` 的针对单节点逻辑）。
- **捷径**：不点一级栏，直接点页面上的图/字 = 进对应模式 + 已选中，一步到位。一级栏保证找得到，直接点保证够快。
- ~~「删除」：二次确认 → 删整页……居中弹窗、确定左取消右~~ **【本次搁置，见上】** 删页无后端通道，随删页功能一起另开分支；届时删除确认用居中弹窗（同分享）、确定在左取消在右。

### 两种背景，分开两处（不要再混）

| | 入口 | 作用对象 | 复用哪个现成弹窗 |
|---|---|---|---|
| **Page background（页面底色）** | 编辑态一级栏「背景」 | 当前这一页的底 | 现有 mes 取色弹窗：`Cancel / Page background / Done` 头 + **Palette / Picker 两 tab** + 大色板网格 + `No background` |
| **Board background（画板背景/垫底）** | 浏览态左下角背景图标 | 整块画布垫底（`#boardBg`） | 现有 `board-bg-sheet`：标题 + ✕ + 色板格（首格斜线=无）+ Images 预设行 + 上传，走 `applyBoardBackground` |

- **这两个弹窗都是已定稿的成品，落地一个像素都不改、不重画**——本次只负责把它们接到新的入口位置。
- 画板背景是全局的，编辑单页时不出现；页面底色是每页的，编辑该页时在一级栏里改。

## AI 入口

- **右下角固定的小气泡**（46px 圆形，纯图标），不进一级栏，浮在缩略条/一级栏**上方**，两个态同一位置。点开升起对话，气泡隐藏。视觉语言接现有 `chat-fold-expand` 收起气泡。
- **品牌化**：背景用 logo（`logo-yujee.svg`）的 `#13B8A6 → #8C5EF4` 渐变（末端带 `#DAF45E`，即 `--grad-green/--grad-purple/--grad-lime`）+ logo 同款 `yj-sheen` 左上沁光；图标是星芒，不是通用聊天气泡。落地引用 `--grad-*` 变量，不硬编码。

## 底部面板高度

- **编辑类二级面板统一 2/3 高（约 66%）**：图片 / 文字 / 更多。（删除确认是居中弹窗，不属这套。）页面永远按同一剩余高度重绘，切换之间不忽大忽小地跳。沿用 `mes` 三段头：取消（快照还原）/ 标题 / 完成（落库重绘）。背景两个弹窗是例外——用它们各自现成的形态（Page background 的 Palette/Picker 弹窗、Board background 的 board-bg-sheet），不套这套 2/3 规则。
- **AI 对话是可变高度**：可拖高、可收起，2/3 起步。内容持续变长，锁死半屏憋屈。这条与现有聊天面板（46vh 默认、150px–90vh 可拖、能收成气泡）一致。
- **导出、分享保持现状不套新弹窗**：导出走现有 `openExportMenu`，分享走现有 `shareLink`。

## 顶栏（按移动端规范重排）

依据 Apple HIG（触点 ≥44×44pt、导航栏 44pt、状态栏/home indicator 安全区）与 Material 3（触点 ≥48dp、间距 ≥8dp、导航栏右侧动作 ≤3 个）：

- 状态栏安全区 + 底部 home indicator 安全区都用 `env(safe-area-inset-*)`，不写死。
- **头像去掉**（编辑器用不到，账号收进「更多」）。
- **导出从实心黑 pill 换成图标**，与分享、更多同份量（导出是低频动作，不该全屏最重）。
- 右侧固定三枚 44pt 图标：**分享 · 导出 · 更多**。
- 「更多」sheet 放：保存到云端 · 重命名相册 · 语言 · 退出编辑器。
- **画布状态类控件（换背景、一屏几页）落在左下角**，不进导航栏 —— 导航栏是"离开这屏去哪"，画布控件是"这屏怎么看"。

## 手势契约

先看态，再看目标。浏览态关掉元素级监听；编辑态"拖"只在二级面板已选中的图上成立 → 机制上消灭"想拖图结果画布飘走"。

| 手势 | 浏览态 | 编辑态 |
|---|---|---|
| 单指上下滑 | 不响应（画布不滚） | 页面超出可视高度时滚页，否则不响应 |
| 单指左右滑 | 上一屏 / 下一屏 | 上一页 / 下一页 |
| 单指轻点 | 点某页展开；点缩略条跳屏 | 点图/字直达二级工具；点空白收面板 |
| 单指按住拖 | 缩略条内横向拖 | 仅在二级面板已选中的图上 = 改构图 |
| 双指捏合 | 1/2/4 三档切（等同点左下角数字钮） | 【本次搁置】临时放大看细节；松手非 1.0 倍则 debounced 重绘落定清晰度。需 transform 临时层 + 松手 debounced 重绘，与本分支「满屏靠重绘、不靠 transform 放大」的取向另议，作为后续（#304 Task15） |
| 双击 | 等同轻点 | 复位缩放 |
| 长按 | 不用 | 不用（避开系统文本选择菜单） |

画布取消上下滚后，剩余冲突只有"左右滑翻页 vs iOS 左缘返回"，靠左缘 20px 让位解决。

## 技术方案（编辑通道零改动）

关键事实：所有编辑逻辑（选页、图片拖动缩放、文字内联编辑、工具条定位）**委托绑定在 `#ovGrid` 一个容器上**（`EditorPort.tsx:2406-2429`）。只要页面仍是 `#ovGrid` 里的 `.ov-page` 格子，编辑能力一行不改。

- **浏览态** = `#ovGrid` 只渲当前那一屏（1/2/4 页），居中不滚；`#boardBg` 原样垫底。
- **换档** = 改 `grid-template-columns` + 按新格子宽度重绘那几页。非 CSS 缩放。
- **编辑态** = 目标页宿主格子撑到满屏，**重新 `paintEl`**，按新 `clientWidth` 重算 scale。**不用 transform 放大** —— `faceHTML`（`EditorPort.tsx:1278`）把 scale 写死进 innerHTML，正是因为 transform 放大低分辨率位图快照永远糊。元素坐标即真实 DOM 坐标，`positionElementToolbar` 无需变换矩阵分支。
- **缩略条** = 复用现有缩略图渲染 + 横排当前项高亮；`+` 走现有新增页通道。
- **二级面板** = 复用 `mes` 的 DOM 与逻辑，把"66vh 满遮罩"改成参与 `--dock-h` 记账的固定 2/3 高面板；图片编辑并入底部面板（滑块全宽）。
- **底部记账** = 一个 `--dock-h`，同时刻只一个住户；画布可视高度 = 屏高 − 顶栏 − 位置条 − `--dock-h`；删掉硬编码 220px。
- **顶栏** = 移动端分支重排右侧动作区，头像与画布控件移出；桌面端顶栏不动。
- **响应式判定源** = 把散在十几处的 `matchMedia('(max-width:767px)')` 收敛成单一来源。
- **新增 `mobile-canvas.ts`**：态机 + 档位 + 手势 + `--dock-h` 调度，约 400 行；`EditorPort.tsx` 只加挂载点，不拆那 4685 行。
- **桌面端（`min-width:768px`）行为原样保留**，无限画布仍是桌面主路径。

## 明确不做

- 不动桌面端；不改 Agent 契约 / PATCH 通道 / 模板渲染。
- 不拆 `EditorPort.tsx`（该拆但不在本分支）。
- 不做手机端自由拖拽排版（元素位置由模板定，同桌面）。
- 封面/结尾页在单页流里当普通页处理。
