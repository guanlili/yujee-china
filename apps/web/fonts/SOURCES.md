# Album font sources

All album fonts are licensed under the SIL Open Font License 1.1. Chinese
fonts stay in this server-only directory and are subset per album; Latin fonts
are served from `public/fonts/`. The shared license text is
`public/fonts/OFL-1.1.txt`.

## Retained pre-existing assets

These files already existed in the repository and remain covered by their
adjacent OFL files. They are listed here so the runtime catalog has one asset
inventory.

- Server-only: `NotoSansSC-Regular.ttf`, `NotoSerifSC-Regular.ttf`
- Public: `EBGaramond.ttf`, `Inter.ttf`, `JetBrainsMono.ttf`, `Lora.ttf`,
  `WorkSans.ttf`, `Poppins.ttf`, `Raleway.ttf`, `PlayfairDisplay.ttf`,
