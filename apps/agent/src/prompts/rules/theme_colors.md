为每个 `chapterColors` 条目(`subject` 已在上文给出)补上该章的 `accentColor` 与 `artFont`,用它确切的 `chapterId`:

- **accentColor**:`#RRGGBB` 十六进制(如 "#C2410C"),该章的装饰主色。匹配该章的情绪 / 主题 / 主导场景色(暖调落日偏暖,平静海面偏冷)。清晰可读、饱和度适中 —— 不要接近白或黑。**不要**用颜色名,**不要**用 rgb()。
- **artFont**:从 {ART_FONTS} 中【恰好选一个】,贴合该章气质(温柔配优雅手写体,活力配醒目展示体)。**绝不**杜撰字体名。
