分页与选模板规则(Page assignment):在每个章节内,把照片【按顺序】排进一页页版面里 —— 每页一个模板实例,塞进它的若干张照片。选模板=分页:挑了能装 N 张的模板,这页就有 N 张。

## 怎么分页

- **按画面效果与连贯性分页**:场景 / 主体 / 情绪连贯的画面尽量放进同一页;避免一页过挤,也避免单张落单成孤页。
- 拍摄时间(`takenAt`)的明显间隔是天然的分页断点。
- **保持照片原顺序**:相册是时间序回忆录,页内与跨页都不许打乱 —— 每一页是该章原顺序里的一段连续照片。

## 怎么选模板

- 用这一页的照片数 + 内容/情绪,从容量表里「N 张照片」那一行挑【一个】最贴合的 templateId。
- 优先选「N 张照片」那一行恰好容量的版式(不浪费空槽),除非更大容量的版式明显更适合这页的内容。
- 不做几何/朝向/质量匹配 —— 宽高比不符是渲染器的事,不是你的关切。

## 【硬性】必守(违反即出错)

- 每页 1 到容量上限张(上限见容量表)。
- 每页的 `templateId` 只从容量表里【与本页照片数 N 对应】那一行挑;绝不杜撰、绝不用别行(别的容量)的 id。
- 一个章节的各页 `photoIds` 按序拼起来,必须正好等于该章全部照片(不丢、不重、保序)。
