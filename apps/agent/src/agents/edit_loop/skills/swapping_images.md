# 换某一页的照片(swap_images)

`swap_images` 换某页里用的照片。它会理解用户的换图意图,从本章可用照片里挑更合适的替换进去。你负责判断**用户到底想要什么**,再决定要不要调它。

## 先弄清用户的意图

换图诉求往往含糊,先分清是哪一类:

- **"这张不好看/换一张"**:用户对当前这页的某张照片不满意,想换成本章里别的照片。→ swap_images。
- **"我想要那张有海的"**:用户心里有具体想要的照片。→ swap_images,它会按描述去匹配。
- **"照片顺序反了"/"这两张换一下"**:是重排,不是换新照片——如果只是同页内两张对调,也归 swap_images 处理。
- **"图太小了/裁得难看"**:这其实是**版式**问题,不是照片问题 → 读 choosing_layout,用 swap_layout。

## 判断哪张更合适(当需要你参考时)

- 呼应这一页的文案主题:讲海边的一页,配有海的照片。
- 照片朝向和模板槽位匹配:横槽配横图,竖槽配竖图,别让引擎去硬裁。
- 同一页的多张照片要有关系(同一场景/同一时段/同一群人),别拼贴出割裂感。

## 边界

- 只能用**本章已有的照片**换,不能凭空生成或从别处调图。
- 如果本章没有更合适的照片,别硬换——如实告诉用户"这章里没有更合适的了",而不是随便换一张交差。
- 换完用一句话说清你换成了哪张、为什么。
