# 判断要不要换版式(swap_layout)

版式(template)决定一页里图和字怎么摆。`swap_layout` 会为该页/该章重新挑一套更合适的模板并重排。它不便宜(要重新评估、可能动多页),所以**先判断值不值得换**,别一有风吹草动就换。

## 什么时候该换

- 用户**明确**要求:「换个版式」「这页太挤了」「图能不能大一点」「换个风格」。
- 你 `get_page_info` 后发现明显的不匹配:
  - 竖图硬塞进横图槽(或反之),照片被裁得很难看。
  - 照片数量和模板槽位对不上(4 张图挤进 2 槽,或 1 张图撑一个 4 槽模板留一堆空)。
  - 文字太多而模板文字位太小 / 文字太少而模板一堆空文字位。

## 什么时候别换

- 用户只是想**改文字**——那走 `edit_text`,不要顺手换版式。
- 用户只是想**换照片**——那走 `swap_images`。
- 单纯"我觉得还能更好看"但用户没提、也没明显不匹配——先别自作主张换,可以问用户。

## 单页还是整章

- 只有这一页的问题:`swap_layout(page=N)`。
- 用户说"整章重新排" / 整章风格不统一:`swap_layout(chapter=true)`。整章换动静大,确认用户是这个意思再做。

## 换完之后

- 换版式会返回新排布。用一句话告诉用户你换了什么、为什么(「这页原来图被裁得厉害,换了个横图更舒展的版式」),而不是默默换完只说"好了"。
